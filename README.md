# 📉 Gradient Descent Implementation

## 📌 Overview
This repository contains an implementation of **Gradient Descent**, one of the most important optimization algorithms used in Machine Learning and Data Science.

Gradient Descent is used to minimize a cost function by iteratively updating parameters in the direction of the negative gradient.

---

## 🚀 Features
- Implementation from scratch (no high-level libraries)
- Supports:
  - Batch Gradient Descent
  - Learning rate tuning
- Visualization of cost reduction (if included)
- Easy-to-understand code structure

---

## 🧠 Concept

Gradient Descent updates parameters using the formula:

\[
\theta = \theta - \alpha \cdot \nabla J(\theta)
\]

Where:
- **θ (theta)** → Model parameters  
- **α (alpha)** → Learning rate  
- **∇J(θ)** → Gradient of the cost function
